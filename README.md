# Konsolda Kripto Fiyat Takip Uygulaması

Bu proje, **Python** ile yazılmış, tamamen **konsol (CLI)** üzerinde çalışan bir kripto para fiyat takip aracıdır.  
Kullanıcıdan bir kripto para **sembolü** (örnek: `BTC`, `ETH`, `SHIB`, `DOGE`) alır ve **CoinGecko API** üzerinden o coine ait tüm bilgileri gösterir.

---

## 🚀 Özellikler
-  CoinGecko API’den canlı veri çekme  
-  Kripto para sembolü (ticker) ile fiyat sorgulama  
-  24 saatlik değişim oranı (yüzde)  
-  Geçersiz sembollerde hata kontrolü
-  İstek listesi takip etme
